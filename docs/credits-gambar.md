# Kredit gambar — Prototype Sertikom

Prototype ini tidak menggunakan foto orang, gambar hasil generatif, atau aset stok eksternal. Seluruh ilustrasi adalah SVG vektor orisinal yang dibuat khusus untuk prototype dan disimpan secara lokal di `assets/img/`.

## Daftar aset

- `sertikom-logo.svg` — mark logo Sertikom.
- `hero-dashboard.svg` — ilustrasi dashboard kompetensi pada hero landing page.
- `school-building.svg` — ilustrasi gedung sekolah untuk konteks institusi.
- `program-web.svg` — ilustrasi program pengembangan web.
- `program-network.svg` — ilustrasi program jaringan komputer.
- `program-design.svg` — ilustrasi program desain komunikasi visual.
- `program-data.svg` — ilustrasi program data dan analitik.
- `program-marketing.svg` — ilustrasi program pemasaran digital.
- `program-cloud.svg` — ilustrasi program cloud dan infrastruktur.

## Catatan penggunaan

- Aset dimuat dari folder lokal sehingga tetap tampil tanpa koneksi internet.
- Logo sekolah, LSP, BNSP, dan mitra resmi belum dimasukkan; semua mark institusi di prototype adalah placeholder teks dan harus diganti dengan aset resmi yang memang diizinkan.
- Untuk deploy publik, cek kembali lisensi, atribusi, serta kesesuaian crop sebelum produksi.
